# Micron OS

The house: shell, apps, configs, deploy, and the server that puts the face
on screen. An operating system layer designed so its resident AI is a
COMPONENT -- swappable, renameable, replaceable.

The reference butler lives in a sibling repository: **Alfred** (cloned to
~/Alfred; the deploy fetches him automatically). Bring your own instead if
you have one: the mind is one config line, the persona one text file.

Start here: MICRONOS.md (what this is), OWNERSHIP.md (the road off the
distro), docs/IMAGE.md (install it as its own thing), SECURITY.md (the
house rules).
